## 4. Database Schema - Exact columns

### chats-related tables

**conversations**
- id: text (PK) - e.g., 'group-<uuid>', 'dm-<uid1>_<uid2>'
- type: text NOT NULL CHECK (type IN ('group','dm'))
- class_id: uuid (FK -> classes.id ON DELETE CASCADE, NULL allowed for pure DMs though in this app groups tied to classes; DMs may have NULL class_id)
- name: text NOT NULL DEFAULT ''
- created_at: timestamptz NOT NULL DEFAULT now()

**conversation_participants**
- conversation_id: text NOT NULL (FK -> conversations.id ON DELETE CASCADE)
- user_id: uuid NOT NULL (FK -> profiles.id ON DELETE CASCADE)
- PRIMARY KEY (conversation_id, user_id)
- Index on user_id

**messages**
- id: uuid PRIMARY KEY DEFAULT gen_random_uuid()
- conversation_id: text NOT NULL (FK -> conversations.id ON DELETE CASCADE)
- sender_id: uuid NOT NULL (FK -> profiles.id ON DELETE CASCADE)
- text: text NOT NULL DEFAULT ''
- attachment_path: text (nullable) - path in chat-attachments bucket
- attachment_name: text (nullable)
- mime_type: text (nullable)
- size_bytes: bigint (nullable)
- created_at: timestamptz NOT NULL DEFAULT now()
- Index on (conversation_id, created_at)

**conversation_last_message** (VIEW)
- conversation_id: text
- text: text (last message text)
- created_at: timestamptz

### classes-related tables

**classes**
- id: uuid PRIMARY KEY DEFAULT gen_random_uuid()
- name: text NOT NULL
- section: text NOT NULL
- code: text NOT NULL UNIQUE
- teacher_id: uuid NOT NULL (FK -> profiles.id ON DELETE CASCADE)
- created_at: timestamptz NOT NULL DEFAULT now()
- Indexes: (teacher_id), (code)

**class_members**
- class_id: uuid NOT NULL (FK -> classes.id ON DELETE CASCADE)
- student_id: uuid NOT NULL (FK -> profiles.id ON DELETE CASCADE)
- joined_at: timestamptz NOT NULL DEFAULT now()
- PRIMARY KEY (class_id, student_id)
- Index on (student_id)

### Related tables (referenced by chats/classes)
**profiles** (referenced by FK): id (uuid PK), name, username, initials, avatar_url, role ('teacher'|'student' NULL), created_at
**posts**, **post_likes**, **comments** (for feed context)
**assignments**, **submissions** (assignments tied to classes)
**announcements**, **announcement_reads** (announcements tied to classes)
**notifications** (has class_id, conversation_id, actor_id, etc.)
